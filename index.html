Autotype

A compact typing app for Windows and Linux, with custom Start/Stop shortcuts, instant typing, adjustable delay and dark/light themes.

Download Windows or Linux packages · Installation guide

Debian / Ubuntu

Add the signed apt feed once, then use your usual package updates.

sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://jeremiah-c27.github.io/autotype-packages/apt/autotype-archive-keyring.gpg | sudo tee /etc/apt/keyrings/autotype.gpg >/dev/null
sudo chmod 0644 /etc/apt/keyrings/autotype.gpg
echo 'deb [arch=amd64 signed-by=/etc/apt/keyrings/autotype.gpg] https://jeremiah-c27.github.io/autotype-packages/apt/ stable main' | sudo tee /etc/apt/sources.list.d/autotype.list >/dev/null
sudo apt update
sudo apt install autotype

Ubuntu 22.04+ / Debian 12+, amd64. Signing-key fingerprint. Wayland needs desktop keyboard-control and shortcut permissions.

Windows

The portable executable works now. The winget catalog command will become available after Microsoft accepts the community submission:

winget install --id JeremiahC27.Autotype --exact

Windows x64. The installation guide also covers local winget manifests while review is pending.
